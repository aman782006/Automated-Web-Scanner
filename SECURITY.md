# Security Policy

## Responsible Use & Legal Disclaimer

**The Automated Web Security Scanner is built for authorized educational testing, defensive posture evaluation, and security research purposes only.**

- Only scan targets that you own or have obtained explicit, written authorization to audit.
- Do NOT use this tool against third-party systems without prior permission.
- Unauthorized scanning may violate computer crime and misuse legislation.
- The project maintainers accept no liability for misuse, damages, or legal repercussions resulting from the operation of this software.

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project (e.g., SSRF bypass, denial of service, CSRF issue, or injection flaw), please report it responsibly:

1. **Do not open a public issue.**
2. Send an email describing the issue, impact, and reproduction steps to **nishadyash99@gmail.com**.
3. Allow reasonable time for the issue to be evaluated and addressed before public disclosure.
